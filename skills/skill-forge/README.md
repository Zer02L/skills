# Skill Forge

Мета-скил для проектирования, сборки, аудита, оптимизации и бенчмаркинга агентских скилов под кросс-агентную среду: **Antigravity**, **Codex**, **Claude Code**, **Gemini CLI**, **OpenCode** и **Skills Manager**.

Основной манифест скила: [`SKILL.md`](SKILL.md).

---

## Сравнение с аналогами от Anthropic и OpenAI (`skill-creator`)

В экосистемах Anthropic (Claude Code) и OpenAI (ChatGPT / Codex) эталоном для создания навыков является `skill-creator` (расположенный в каталоге `openai/skills/.system/skill-creator` и референсном репозитории Anthropic).

Хотя `skill-creator` и `skill-forge` решают задачу создания скилов, они исходят из принципиально разных философий:

* **`skill-creator` — это «Prompt & Behavioral Iteration»:**  
  Инструмент ориентирован на промпт-инжиниринг, многократные стохастические запуски через LLM (`claude -p`), автоматический подбор формулировок описания и слепое сравнение генерации текста/кода/документов.
* **`skill-forge` — это «Systems & Token Engineering»:**  
  Инструмент ориентирован на инженерию надёжных инструментов (CLI, Flatpak, Docker, MCP), жесткий контроль бюджетов токенов, детерминированные хуки авто-запуска и защиту шелла от опасных команд.

### Сравнительная таблица

| Критерий | `openai/skills/skill-creator` | `skill-forge` |
| :--- | :--- | :--- |
| **Вес в контексте** | Тяжеловесный монолит `SKILL.md` (**~485 строк, ~8 300 токенов**). | Ультра-компактный `SKILL.md` (**48 строк, ~1 150 токенов**) + `references/` по требованию. |
| **Исследование тулов (Probe)** | **Отсутствует.** Модель сразу переходит к тексту инструкций. | **Обязательная фаза `Probe`:** исследование реального `--help`, ограничений песочницы, замер задержки и объёма вывода *до* написания правил. |
| **Зависимости** | Требует `PyYAML`, утилиту `claude -p`, веб-сервер для вьюера. | **100% чистый Python 3 stdlib**, нулевые внешние зависимости, автономная работа в любых средах (CI, VPS, контейнеры). |
| **Управление триггерами** | Только стохастический семантический `description`. | **Гибрид:** семантический `description` + детерминированный `hook-triggers.json` (промпт-роутер + `deny_shell`). |
| **Тестирование триггеров** | Через повторные вызовы LLM (`claude -p`), дорого и медленно. | Мгновенный тест регулярок через `scripts/test-triggers.py` с проверкой паритета Python `re` и JS `RegExp` (включая кириллицу). |
| **Обратная связь (Feedback)** | Локальный веб-сервер, ручной экспорт `feedback.json` через загрузки браузера. | Автономный HTML-отчёт со сбором заметок и кнопкой **«Copy Feedback for Agent»** в буфер обмена в 1 клик. |
| **Аудит бюджетов** | Нет контроля — приводит к раздуванию контекста. | Встроенный `scripts/audit-skill.py` аппаратно контролирует idle- и active-токены каждого слоя. |

### Где `skill-forge` превосходит аналоги:

1. **Экстремальная токен-эффективность (Lean Budget):**  
   Агент не тратит полезное контекстное окно на чтение огромных мета-инструкций. `SKILL.md` содержит только ключевые правила и архитектуру; всё остальное загружается точечно через Progressive Disclosure.
2. **Защита от циклов проб и ошибок (Probe First):**  
   Для CLI- и API-скилов сначала замеряется поведение реального бинарника, проверяется монтирование путей песочниц и отлавливаются параметры, вызывающие откаты (как `crossAlign` в FigCraft). Это исключает галлюцинации модели на первом же вызове.
3. **Безопасность и гарантированное срабатывание:**  
   Благодаря `hook-triggers.json` скил не зависит от того, «захочет» ли модель вызвать скил по описанию. Роутер перехватывает намерения пользователя за 1 мс, а директива `deny_shell` блокирует небезопасные или дорогие команды в терминале.
4. **Кросс-агентный и офлайн рантайм:**  
   Скрипты не ломаются без `pip install` или `npm install` и готовы к работе на любых машинах.

---

### В чём `skill-forge` уступает аналогам (осознанные компромиссы):

1. **Нет встроенного автоматического LLM-тюнера описаний:**  
   В `skill-creator` есть скрипты `run_loop.py` и `improve_description.py`, которые через `claude -p` прогоняют 20 запросов по 3–5 итераций, автоматически подбирая текст для `description`. В `skill-forge` эта автоматизация сознательно исключена: тратить миллионы токенов на подбор слов экономически нецелесообразно при наличии бесплатного детерминированного regex-хука.
2. **Упрощенный UI для ревью:**  
   В `skill-creator` встроен мощный HTTP-сервер с возможностью предварительного просмотра сложных артефактов (docx, PDF, сгенерированные графики). В `skill-forge` формируется легковесный статичный HTML, сфокусированный на ассертах, метриках и мгновенном копировании фидбека в диалог агенту.
3. **Требует инженерной дисциплины:**  
   `skill-creator` ориентирован на нетехнических пользователей («сделай скил из текущей беседы»). `skill-forge` ориентирован на разработчиков: требует соблюдения лимитов токенов, прогона линтеров и написания контрастных негативных тестов (*near-misses*).

## Структура папки `skill-forge`

```text
skills/skill-forge/
├── SKILL.md                       # Компактный манифест и 6-этапный рабочий процесс (≤ 150 строк)
├── README.md                      # Данный документ (сравнение с аналогами и концепция)
├── hook-triggers.json             # Правила авто-хука для universal skill-hook-router
├── assets/
│   └── report.html                # Автономный HTML/CSS/JS шаблон отчёта эвалов
├── references/
│   ├── authoring-guide.md         # Правила текста, структура scripts/_*.py + assets/, regex для хуков
│   └── eval-playbook.md           # Методология A/B тестирования, шаблоны судей (Grader, Comparator, Analyzer)
├── scripts/
│   ├── _spec.py                   # Внутренний канонический парсер frontmatter и валидатор хуков
│   ├── audit-skill.py             # Аудит структуры, портативности и токен-бюджетов (stdlib Python 3)
│   ├── test-triggers.py           # Проверка триггеров на Python re, JS RegExp и live router
│   └── eval-summary.py            # Агрегатор A/B результатов в benchmark.json, benchmark.md и HTML
└── evals/
    └── trigger-tests.json         # Набор положительных и near-miss тестов для skill-forge
```

## Быстрые команды

```bash
# Проверить токен-бюджеты (включая жёсткие целевые лимиты), ссылки и автономность
python3 skills/skill-forge/scripts/audit-skill.py --strict --target-strict skills/skill-forge/

# Проверить качество триггеров и кросс-рантайм регулярных выражений
python3 skills/skill-forge/scripts/test-triggers.py skills/skill-forge/ --live-router --js-check

# Собрать отчёт по итерации эвалов с интерактивным полем для фидбека
python3 skills/skill-forge/scripts/eval-summary.py <workspace>/iteration-1 --skill-name "my-skill" --html <workspace>/iteration-1/report.html

# Единый quality gate всего репозитория (compile, validate, audit, triggers, unittest)
./scripts/check.py --require-js
```
